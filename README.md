# Weather Data Analysis

Python application developed as part of the Programming Computers course at PUCRS.

## About

This project analyzes historical meteorological data from Porto Alegre, Brazil, using data stored in a CSV file.

The application allows the user to select a period and visualize different meteorological measurements, as well as perform specific analyses on the dataset.

## Features

* Read and process meteorological data from a CSV file
* Filter records by month and year
* Display precipitation, maximum and minimum temperature, relative humidity and wind speed
* Identify the month and year with the highest accumulated precipitation
* Calculate average minimum temperature by year for a selected month
* Calculate the overall average temperature
* Generate a bar chart using Matplotlib
* Validate user input and selected periods

## Technologies

* Python
* Matplotlib
* CSV
* Lists and dictionaries
* Functions
* Conditional statements and loops
